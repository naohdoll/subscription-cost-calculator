# Subscription Cost Calculator

**[Open the calculator →](https://naohdoll.github.io/subscription-cost-calculator/)** ・ [日本語版](https://naohdoll.github.io/subscription-cost-calculator/ja/)

A free, private subscription cost calculator. Add your subscriptions and instantly see:

- your **monthly and yearly total**, for any billing cycle (monthly, quarterly, every 6 months, yearly, every 2 years)
- a **breakdown by category**
- how much you'd **save per year** by cancelling the ones you marked "Cancel"

No sign-up, no tracking. Everything is stored only in your own browser (local storage). Export to CSV anytime.

---

無料のサブスク料金計算ツールです。契約中のサービスを追加するだけで、月額・年額の合計、カテゴリ別の内訳、解約した場合の年間節約額がわかります。登録不要で、データはブラウザ内にだけ保存されます。
